# Bank AI MultiBank Risk Intelligence

AI platform to parse 10-K / 10-Q filings, extract MD&A and Risk disclosures, compare banks, and generate executive summaries.

## Features
- MD&A extraction
- Risk factors extraction
- Sentiment scoring
- Dashboard

## Run

pip install -r requirements.txt

streamlit run app.py
